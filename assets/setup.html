Create your wallet

This server holds a small "till" wallet — like cash in a register — that receives payments and empties into your own wallet automatically. It lives in the barkd sidecar next to this server.

Write down your recovery words

These words are the root backup of the till: with them, the wallet can be rebuilt on any machine. They are shown once. Never paste them into a chat, a document, or an AI assistant.

Connect to the wallet

The payments server talks to the wallet with a token. Run this on the machine running barkd and paste the result — the AI never sees it:

docker compose exec barkd barkd --datadir /data secret show

Name your store

The store is what your shop (or the WooCommerce plugin, later) authenticates as when it creates invoices.
