# Roadmap

Plain and short. Dates are not promised; order is. The owner decides what ships.
Detailed plans live in `docs/dev/`.

| | |
| --- | --- |
| **Now: WooCommerce** | Live. Lightning and Ark checkout, automatic payout to your own wallet, backups, one-tap updates, emergency withdrawal. Still experimental: start small. |
| **In testing: invoices** | Get paid in bitcoin without a web shop: make an invoice on the Invoices tab and send it as text or a picture by email or chat; it can be paid for 24 hours, by Lightning or Ark. In 0.3.3 release candidates, off until you turn it on in Settings; paid on real money by Lightning and Ark, more checks to come. Plan: [docs/dev/INVOICES.md](dev/INVOICES.md). |
| **Then (v0.5)** | Invoice polish, and a guided move from the free address to your own domain. |
| **Before 1.0 (v0.6 to v0.9)** | Release candidates: a second independent review of the money-sending code, ARM servers, reproducible builds. |
| **1.0** | WooCommerce and invoices, after a good stretch of real-money use. |
| **After 1.0: Shopify** | Later than first hoped: Shopify's recent changes make outside payments harder, so it needs its own careful plan ([docs/dev/SHOPIFY.md](dev/SHOPIFY.md)). |
| **Also later** | Branta address checks, Lightning and silent-payment payouts, refunds, automatic updates. |
