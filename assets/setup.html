Use a hosting service that gives you https automatically, then set your public address (EBP_PUBLIC_BASE_URL) to the https:// address and open this page there. See the setup guide.

Enter your setup code

To keep strangers out, the server made a one-time setup code when it started. Look for SETUP CODE on the screen where you started the server and type it here.

Create your wallet

This server holds a small "till" wallet — like cash in a register — that receives payments and empties into your own wallet automatically. It runs as its own small program (called barkd) next to this server.

This choice is permanent for this server. The wallet is made for one network and cannot be moved. To switch later, you need a new server.

REAL MONEY. This server will take real bitcoin. It is experimental: keep amounts small. This cannot be changed later.

Leave this as the page fills it in: Second's Ark server for the network you chose.

Moving to a new server?

Restore your wallet

Type the 12 recovery words you wrote down when you first set up your server. The wallet and the money in it come back from these words. Type them only here, nowhere else.

The words are sent to your own server only, used once to rebuild the wallet, and never stored or logged. Coins can take a round or two (a few minutes on the practice network) to appear after a restore.

Bring back your orders and settings

Your wallet is restored. If you also have the backup file you downloaded from your old server (it ends in .ebpbackup), pick it here to bring back your order history, your payout address, your admin password and your shop connection.

Write down your recovery words

These words are the root backup of the till: with them, the wallet can be rebuilt on any machine. They appear on screen for 60 seconds at a time and are never stored. Never paste them into a chat, a document, or an AI assistant.

These words control only your till — the working balance this server holds until it is moved to your own wallet — not your personal wallet. Keep them private all the same.

Tap “Show my recovery words” to read the words straight from barkd’s one-time --expose-mnemonic ceremony. EBP shows them once and never stores or logs them. After you confirm the backup, the command shown will restart barkd WITHOUT the flag.

Check your paper copy. The words are hidden now. Look at your paper and type the words it asks for. The server checks them; this page never keeps the words.

Connect to the wallet

The payments server talks to the wallet with a token. Run this on the machine running barkd and paste the result:

docker compose exec barkd barkd --datadir /data secret show

Name your store

The store is what your shop (or the WooCommerce plugin, later) authenticates as when it creates invoices.

You will use this to sign in to your admin page from any phone or computer. Store it in a password manager. A few random words works well.

Ark is recommended: your money is moved to your own wallet at very small amounts, so little is ever held on this server. On-chain works too. Examples. Ark wallets: Arké, Noah. On-chain wallets: Sparrow, Nunchuk, Liana.

Danger: money sent to this address could be lost for good. Bitcoin payments cannot be undone, and nobody can get lost money back. If you are only testing with play money you can still go on.

Payments land in a small "till" wallet on this server and are emptied to this address, which should belong to a wallet you control. You can add or change it later in Settings. Changing it later takes a day and needs your admin password, for safety.
