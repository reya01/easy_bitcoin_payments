Dashboard shell

This is the mobile-first shell for the merchant dashboard. The payment loop is implemented against the barkd sidecar; balances, payment history, the expiry queue, ASP status, and the accounting export are Phase 1/2 dashboard work. This build is EXPERIMENTAL — use signet or regtest only.

What works today

  • Invoice API: create, get, list, cancel — per-store API keys
  • Hosted checkout page at /i/<invoice id>
  • Polling payment watcher with a persisted history cursor
  • Signed webhook emitter (HMAC-SHA256, replay window)
  • Health endpoint at /api/v1/health
  • barkd sidecar wallet: Ark + on-chain + Lightning receive

Wallet status

The wallet layer talks to a barkd 0.8.0 sidecar. Without EBP_BARKD_TOKEN the server boots on the stub wallet and observes no payments. This build is not for real funds.
