Try a payment

Makes a payment request so you can see the checkout page. It opens on Lightning: scan its QR code with any Lightning wallet. Use the same kind of coins as this server: play-money coins on a test server, real coins on a real-money one. It shows up below once paid.

On a real-money server this is a real payment. The money lands on your server like any other sale and is paid out to your own wallet later in the usual way. You also need a few extra sats in your wallet for the Lightning network fee. If it has not turned Paid within about 2 minutes, wait a little and check again. Do not pay it a second time.

Emergency: withdraw without the Ark server

A last resort to take your money out on your own if the Ark server is gone or refuses to help. Open it only in an emergency.

ExpandCollapse
For emergencies only. You always hold the keys to this money, so this lets you take it out on your own even if the Ark server is gone or refuses to help. On real money it is new: it has only been tried in small tests so far, so keep only amounts you can afford to lose on this server. This is for emergencies only. It takes several Bitcoin transactions, each paying network fees, and at least a day. Fees can be high, and on small amounts they can be more than the money itself. If the Ark server is working, use Move my money now instead: it is cheaper and faster.
